# API do v0.1

## `POST /upload`

Recebe um PDF completo do processo e dispara o processamento assíncrono.

### Entrada

Multipart form:

- `file`: PDF do processo.

### Resposta

```json
{
  "processo_id": "proc_123",
  "status": "pendente"
}
```

### Status possíveis

- `pendente`;
- `processando`;
- `concluido`;
- `erro`.

## `GET /processo/{id}/status`

Retorna o estado do processamento.

### Resposta

```json
{
  "processo_id": "proc_123",
  "status": "concluido",
  "paginas_extraidas": 42,
  "chunks": 128,
  "erro": null
}
```

## `POST /processo/{id}/chat`

Recebe uma pergunta e responde com base nos trechos recuperados do processo.

### Entrada

```json
{
  "pergunta": "Quais fatos preciso confirmar na audiência?"
}
```

### Resposta

```json
{
  "resposta": "Com base nas páginas 3 e 7, os pontos principais são...",
  "fontes": [
    {
      "pagina": 3,
      "chunk_index": 0,
      "trecho": "..."
    }
  ]
}
```

## Regra de Resposta

Se o sistema não recuperar fonte suficiente, deve responder que não encontrou base no processo, em vez de inventar.
