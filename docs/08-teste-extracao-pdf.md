# Primeiro Teste: Extração de PDF Real Difícil

## Por que este teste vem primeiro

Todo o produto depende de citar páginas corretamente. Se o texto extraído do PDF for ruim, o chat pode parecer inteligente, mas estará sem base confiável.

## PDF ideal para teste

Um processo real anonimizado ou autorizado, com características difíceis:

- páginas escaneadas;
- carimbos;
- assinaturas;
- margens tortas;
- baixa qualidade de OCR;
- documentos misturados;
- páginas longas.

## Saída esperada do teste

Um relatório por página:

- número da página;
- quantidade de caracteres extraídos;
- amostra do texto;
- indicação se a página parece vazia;
- observação sobre qualidade.

## Decisão após o teste

Se muitas páginas vierem vazias ou ilegíveis, o v0.1 precisa incluir OCR. Se a maioria vier legível, OCR fica para fase posterior.
