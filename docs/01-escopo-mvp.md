# Escopo do MVP

## Objetivo do MVP

Permitir que um defensor envie um PDF de processo fictício ou anonimizado e use uma interface única para preparar audiência com apoio de IA e fontes.

## Funcionalidades essenciais

1. Cadastro de caso

- título;
- número do processo;
- área ou tipo de demanda;
- status simples.

2. Upload e leitura de PDF

- receber PDF;
- extrair texto por página;
- registrar limitações de extração;
- preservar origem das informações.

3. Análise orientada à audiência

- visão geral do caso;
- partes e dados principais;
- linha do tempo explicada;
- pontos para confirmar em audiência;
- perguntas sugeridas;
- provas, documentos e pendências;
- alertas de urgência.

4. Chat do caso

- responder perguntas sobre o processo;
- usar somente trechos recuperados do caso;
- mostrar fontes usadas;
- avisar quando não houver base suficiente.

5. Fontes rastreáveis

- exibir página e trecho de origem;
- permitir revisão humana;
- esconder detalhes técnicos do usuário final.

## Fora do MVP

- assinatura, cobrança e planos comerciais;
- multi-tenant de produção;
- OCR avançado;
- integração com sistemas oficiais;
- geração automática de petições finais;
- uso com dados reais sem fase de segurança.

## Critério de sucesso

Um defensor deve conseguir usar um PDF de exemplo e responder:

- "Qual é o caso?"
- "Quais datas importam e por quê?"
- "O que preciso confirmar em audiência?"
- "Que documentos/provas preciso conferir?"
- "De onde veio essa informação?"
