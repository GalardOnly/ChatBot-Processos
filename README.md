# Preparador de Audiência

Ferramenta para ajudar defensores públicos a analisar processos e se preparar para audiências.

O foco do produto é transformar autos processuais em uma experiência prática de trabalho:

- entender rapidamente o caso;
- conversar com o processo por chat;
- montar linha do tempo explicada;
- identificar pontos que precisam ser confirmados em audiência;
- sugerir perguntas;
- listar provas, documentos e pendências;
- sempre mostrar fontes rastreáveis para revisão humana.

## Princípio central

A ferramenta não decide pelo defensor. Ela organiza, explica, pergunta e aponta fontes para acelerar a preparação, mantendo revisão humana obrigatória.

## Estado atual

Projeto reiniciado do zero. Esta primeira etapa cria a base documental e o roadmap antes da implementação.
